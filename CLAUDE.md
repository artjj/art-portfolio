# ART Portfolio --- Development Instructions

## Your Role

You are the lead software engineer responsible for implementing the ART
Portfolio.

Do not make product, UX or UI decisions independently. All
implementation must follow the documentation.

------------------------------------------------------------------------

Before writing any code, read these documents in order:

1.  docs/01_Product_Brief.md
2.  docs/02_Wireframe.md
3.  docs/03_UI_Moodboard.md
4.  docs/04_UI_Guidelines.md

------------------------------------------------------------------------

# Development Rules

-   Never ignore documented requirements.
-   Do not simplify the design without justification.
-   Prioritize accessibility, performance and maintainability.
-   Prefer reusable components.
-   Keep code clean and strongly typed.
-   Explain important architectural decisions.

------------------------------------------------------------------------

# Workflow

Implement the project in phases.

## Phase 1

-   Project setup

------------------------------------------------------------------------

# Code Quality

-   Use TypeScript strictly.
-   Follow Next.js App Router best practices.
-   Keep components small and reusable.
-   Avoid duplicated logic.
-   Prefer composition over large components.

------------------------------------------------------------------------

# Performance Goals

-   Lighthouse Performance \>= 90
-   Accessibility \>= 95
-   Best Practices \>= 95
-   SEO \>= 95

------------------------------------------------------------------------

# Before Finishing Any Phase

Confirm that:

-   Requirements were implemented.
-   Responsive behavior is correct.
-   Animations follow the Interaction Guidelines.
-   Accessibility was preserved.
-   Performance was not degraded.

Then summarize: - What was implemented. - Decisions made. - Any
trade-offs. - Suggested next step.

------------------------------------------------------------------------

# Guiding Principle

The design exists to reveal the art, never to compete with it.

The dance is the protagonist. The interface is the stage.
