# UI Guidelines --- Portfólio Artístico \| ART

## Design Manifesto

> O design existe para revelar a arte, nunca para competir com ela.

Toda decisão de design deve aproximar o visitante da identidade
artística do ART.

Se um elemento existe apenas por estética, sem contribuir para a
experiência, ele deve ser removido.

Cada animação, componente, transição, espaçamento e interação deve
possuir um propósito claro.

**A dança é a protagonista. O design é o palco.**

------------------------------------------------------------------------

# 1. Design Principles

-   Editorial + Street
-   Cinematográfico
-   Minimalista
-   Atemporal
-   Mobile First
-   Performance First

------------------------------------------------------------------------

# 2. Color System

## Base

-   Preto
-   Branco
-   Escala de cinzas

## Accent Color

Azul profundo.

Uso: - Botões principais - Links - Hover - Estados ativos - Pequenos
detalhes

Sensações: - Criatividade - Energia - Intensidade - Sofisticação - Calma

------------------------------------------------------------------------

# 3. Layout System

-   Layout híbrido (full-width e contido)
-   100vh apenas quando fizer sentido
-   Alinhamento misto (centro + esquerda)
-   Respiro médio entre seções

------------------------------------------------------------------------

# 4. Typography

## Filosofia

-   Hierarquia acima da estética
-   Legibilidade acima de tudo

## Hero

-   Display XL
-   ExtraBold
-   Caixa Alta

## Títulos

-   Muito grandes
-   ExtraBold
-   Title Case

## Escala Tipográfica

-   Display XL
-   Display L
-   H1
-   H2
-   H3
-   Body Large
-   Body
-   Body Small
-   Caption

------------------------------------------------------------------------

# 5. Buttons

## Primary

-   Accent Color
-   Cantos levemente arredondados
-   Grande área de clique
-   Hover elegante

## Secondary

-   Fundo transparente
-   Borda fina
-   Hover suave

------------------------------------------------------------------------

# 6. Cards

-   Cantos retos
-   Conteúdo protagonista
-   Hover discreto
-   Pouco texto

------------------------------------------------------------------------

# 7. Navigation

Desktop: - Sticky - Transparente sobre o Hero - Fundo translúcido após
scroll

Mobile: - Menu hambúrguer - Tela cheia ao abrir - Transição
cinematográfica

------------------------------------------------------------------------

# 8. Responsive Design

## Filosofia

Responsive First.

-   Smartphone
-   Tablet
-   Notebook
-   Desktop

A narrativa nunca muda; apenas o layout se reorganiza.

------------------------------------------------------------------------

# 9. Performance

## Princípio

Performance é Design.

Metas: - Lighthouse Performance ≥ 90 - Accessibility ≥ 95 - Best
Practices ≥ 95 - SEO ≥ 95

Boas práticas: - Lazy Loading - AVIF / WebP - Fontes otimizadas -
Animações via GPU - Code Splitting

------------------------------------------------------------------------

# 10. Motion

-   Fade + movimento
-   Velocidade equilibrada
-   Hero cinematográfico
-   Animações apoiam a experiência

------------------------------------------------------------------------

# 11. Cursor

Desktop: - Cursor personalizado - Círculo fino - Feedback em hover

Mobile: - Não utilizar

------------------------------------------------------------------------

# 12. Images

-   Editorial
-   Grande impacto
-   Poucas imagens
-   Muito respiro

------------------------------------------------------------------------

# 13. Videos

Os vídeos são o principal elemento do projeto.

Toda a interface existe para valorizá-los.

------------------------------------------------------------------------

# 14. UX Rules

-   Cada seção possui um único objetivo.
-   A dança é protagonista.
-   Conteúdo antes de efeitos.
-   Responsividade é requisito de produto.
-   Nenhum efeito visual deve comprometer a experiência mobile.
-   O design deve permanecer atual por muitos anos.
