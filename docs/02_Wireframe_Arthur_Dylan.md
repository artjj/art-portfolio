# Wireframe V1 --- Portfólio Artístico \| Art

## Objetivo

Definir a estrutura da página inicial antes da etapa visual.

## 01. Hero

-   Vídeo em tela cheia (loop, sem áudio)
-   Nome artístico: Art
-   Frase de impacto
-   Menu transparente
-   Botões: Watch Reel e Contact
-   Indicador de scroll

## 02. Melhores Trabalhos

-   Grid com 3--5 vídeos
-   Preview no hover
-   Zoom suave
-   Título + contexto
-   Modal com YouTube
-   Navegação entre vídeos

## 03. Estilos

-   Cards: Dancehall, Krump, Hip Hop e Popping
-   Dancehall e Krump em destaque
-   Identidade visual própria para cada estilo
-   Hover com animação discreta

## 04. Trajetória

-   Desktop: timeline horizontal
-   Mobile: timeline vertical
-   Ano + título + descrição curta
-   Foco na evolução artística

## 05. Filosofia

-   Foto grande
-   Frase de impacto
-   Texto curto apresentando a visão artística

## 06. Contato

-   Título de encerramento
-   Texto de convite
-   Formulário (Nome, E-mail, Mensagem)
-   Instagram como principal CTA
-   Links para TikTok e E-mail

## Fluxo

1.  Hero
2.  Melhores Trabalhos
3.  Estilos
4.  Trajetória
5.  Filosofia
6.  Contato

## Princípios

-   Vídeo antes de texto
-   A dança é protagonista
-   Interface limpa
-   Mobile-first
-   Experiência cinematográfica
