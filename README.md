# ART Portfolio

> Portfólio artístico de **ART**, concebido como uma experiência digital
> premium para apresentar sua identidade, trajetória e trabalhos.

------------------------------------------------------------------------

# Objetivo

Criar um portfólio que vá além de um currículo digital.

O visitante deve compreender quem é o ART em poucos segundos, conhecer
seus principais trabalhos e encontrar facilmente uma forma de contato.

------------------------------------------------------------------------

# Estrutura da Documentação

## 01 --- Product Brief

Define a visão estratégica do produto: - Objetivos - Público-alvo -
Posicionamento - Branding - Escopo - Roadmap

## 02 --- Wireframe

Define a arquitetura da experiência: - Estrutura das páginas - Fluxo de
navegação - Hierarquia das seções

## 03 --- UI Moodboard

Define a direção visual: - Referências - Estilo - Atmosfera -
Inspirações

## 04 --- UI Guidelines

Define o Design System: - Manifesto - Layout - Grid - Tipografia -
Componentes - Responsividade - Performance

## 05 --- Interaction Guidelines

Define o comportamento da interface: - Hero - Galeria - Modais -
Microinterações - Motion - Estados - Acessibilidade

## 06 --- Development Specification

Define como o projeto será construído: - Stack - Arquitetura - CMS -
SEO - Testes - Performance - Plano de implementação

## CLAUDE.md

Instruções de trabalho para o Claude Code durante o desenvolvimento.

------------------------------------------------------------------------

# Filosofia

> O design existe para revelar a arte, nunca para competir com ela.

Princípios:

-   A dança é protagonista.
-   O design é o palco.
-   Performance é Design.
-   Responsividade é requisito.
-   Cada seção possui um único objetivo.
-   Toda interação deve parecer física.
